# tinyraycaster
Based on https://github.com/ssloy/tinyraycaster/

There are two files that are notable in this repo right now:
- raycaster.cc is the main program, without notes
- raycast_withnotes.cc has a bunch of notes on various things

Most of this has been tested on Windows and Linux, specifically Zorin (which is based on Ubuntu) and Gentoo
